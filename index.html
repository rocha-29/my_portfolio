Featured labs

Three labs I have planned and not started yet. The descriptions are design goals, not results. Each gets a repository and a full write-up once it is built.

  • Private PKI as code: ACME, mTLS and 24-hour certificates

    PKI/TLS Planned

    Goal: a two-tier internal CA on step-ca that will issue short-lived certificates over ACME to Nginx, Apache and Tomcat, with mutual TLS between services and no manual renewals.

    • Offline root and online intermediate, with a written design note on lifetimes and revocation
    • Expiry and renewal metrics with alerting, plus CA-outage failure drills
    • Planned around the CA/Browser Forum move to 100-day and 47-day certificates
    • step-ca
    • ACME
    • mTLS
    • YubiKey PIV
    • Prometheus
    • Grafana

  • Detection-as-code pipeline with attack simulation

    Detection Planned

    Goal: versioned Sigma rules, tested in CI against recorded attack telemetry and deployed to Splunk, each mapped to MITRE ATT&CK with a runbook.

    • Each rule ships with true-positive and benign test fixtures
    • GitHub Actions lints, tests, converts and deploys rules on merge
    • ATT&CK Navigator coverage layer and false-positive tuning notes
    • Splunk
    • Sigma
    • Sysmon
    • Atomic Red Team
    • GitHub Actions
    • MITRE ATT&CK

  • AWS security baseline in Terraform, attacked and detected

    Cloud Planned

    Goal: a hardened AWS account defined entirely in Terraform, then tested with simulated cloud attacks to check that logging, detections and automated remediation hold up.

    • Least-privilege IAM with no long-lived keys, IMDSv2 and SSM instead of SSH
    • Before and after posture scans with Prowler
    • CloudTrail detections and Lambda auto-remediation for simulated attack techniques
    • AWS
    • Terraform
    • CloudTrail
    • GuardDuty
    • Prowler
    • Lambda
